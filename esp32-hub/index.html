ESP32 Board Family (Beginner to Pro)

Beginner

ESP32 (WROOM-32)

Significance: The classic entry point. Dual-core LX6 CPU up to 240MHz, integrated Wi-Fi + Bluetooth 4.2 BLE.

  • Flash: 4MB
  • SRAM: 520 KB
  • Best For: Basic IoT, Wi-Fi web servers, Bluetooth gadgets.
Intermediate

ESP32-S / WROOM-32S

Significance: Compact surface-mount board base, optimized RF shielding, identical core features with slimmer pin layout.

  • Flash: 4MB - 8MB
  • SRAM: 520 KB
  • Best For: Custom PCB designs and compact embedded devices.
Advanced

ESP32-CAM (AI-Thinker)

Significance: Ultra-cheap video/image processing unit featuring OV2640 camera module and MicroSD card slot.

  • PSRAM: 4MB (Essential for high-res images)
  • Features: Onboard Flash LED, MicroSD Slot.
  • Best For: Security cameras, face recognition, time-lapse photography.
Pro

ESP32-S3 CAM

Significance: Next-gen AI/Vector-processing chip with Dual USB Type-C, Bluetooth 5 (LE), higher clock speed, and native camera hardware support.

  • CPU: Dual-Core Xtensa LX7 with Vector Instructions (TinyML)
  • PSRAM: Up to 8MB Octal PSRAM
  • Best For: Edge AI, Machine Vision, Voice Assistant, high-framerate streaming.

ESP32 Pinout & GPIO Reference

Understanding which pins to use and which ones to avoid is crucial for project stability.

Pin / GPIO Type Primary Function & Significance Usage Note
3V3 / 5V / GND Power 3.3V Output/Input, 5V Vin Input, Ground reference. ⚠️ ESP32 logic is strictly 3.3V!
GPIO 21 & GPIO 22 I2C I2C Communication (SDA = 21, SCL = 22). Default pins for OLED, Accelerometers, Sensors.
GPIO 18, 19, 23, 5 SPI SPI Communication (SCK=18, MISO=19, MOSI=23, CS=5). Used for TFT Displays and SD Card modules.
GPIO 34, 35, 36, 39 ADC (Input) Analog-to-Digital Conversion (ADC1). Input ONLY! No internal pull-up/pull-down resistors.
GPIO 0, 2, 12, 15 Strapping Determines boot mode (Flashing vs Normal Execution). ⚠️ If held wrong at boot, code won't upload!
GPIO 1 (TX) / 3 (RX) UART Serial Communications with PC. Avoid using for external components if debugging.

Common Sensors for ESP32 Projects

DHT11 / DHT22

Type: Temperature & Humidity Sensor

Protocol: 1-Wire Digital Signal

Significance: Essential for weather stations and home automation monitoring.

HC-SR04 Ultrasonic

Type: Distance / Range Sensor

Protocol: Trigger / Echo Pulse Timing

Significance: Perfect for obstacle detection and water tank level measurement.

ST7735 / ILI9341 TFT Display

Type: Color LCD Screen

Protocol: High-Speed SPI Interface

Significance: Renders graphs, custom graphics, menus, and camera preview frames.

MPU6050

Type: 6-Axis Gyroscope & Accelerometer

Protocol: I2C

Significance: Used for orientation, motion tracking, and robotics balancing.

Project Codes & Circuit Setup

1. LED Blinking (Hello World)

Required Components: ESP32 Board, 1x LED, 1x 220Ω Resistor, Breadboard, Jumper Wires.

// ESP32 LED Blink Program
const int ledPin = 2; // Built-in LED on GPIO 2

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH); // Turn LED ON
  delay(1000);                // Wait 1 second
  digitalWrite(ledPin, LOW);  // Turn LED OFF
  delay(1000);                // Wait 1 second
}

2. TFT Display (ST7735 SPI Screen) Setup

Required Components: ESP32, 1.8" ST7735 TFT Display (128x160), Adafruit_GFX & Adafruit_ST7735 libraries.

#include <Adafruit_GFX.h>
#include <Adafruit_ST7735.h>
#include <SPI.h>

// Pin Definitions for ESP32
#define TFT_CS   5
#define TFT_RST  4
#define TFT_DC   2

// Hardware SPI setup (SDA=23, SCL=18)
Adafruit_ST7735 tft = Adafruit_ST7735(TFT_CS, TFT_DC, TFT_RST);

void setup() {
  tft.initR(INITR_BLACKTAB);
  tft.fillScreen(ST7735_BLACK);
  
  tft.setCursor(10, 30);
  tft.setTextColor(ST7735_GREEN);
  tft.setTextSize(2);
  tft.print("ESP32 HUB");

  tft.setCursor(10, 60);
  tft.setTextColor(ST7735_WHITE);
  tft.setTextSize(1);
  tft.print("TFT Display Active!");
}

}

3. ESP32-CAM Web Video Streamer

Required Components: ESP32-CAM module, FTDI Serial Programmer / USB-to-TTL Converter.

#include "esp_camera.h"
#include <WiFi.h>

const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_WIFI_PASSWORD";

void startCameraServer();

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  
  Serial.println("\nWiFi Connected!");
  Serial.print("Camera Stream URL: http://");
  Serial.println(WiFi.localIP());
}

void loop() {
  delay(10000);
}
